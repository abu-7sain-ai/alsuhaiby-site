# موقع محمد الصهيبي

موقع شخصي يحوّل كل فيديو من فيديوهات محمد الصهيبي إلى صفحة مكتوبة كاملة، عشان تطلع في بحث قوقل وفي إجابات الذكاء الاصطناعي.
كل صفحة فيها: الفيديو، وملخص من سطرين، ومقال كامل، وأسئلة وأجوبة. الدستور الكامل في ملف `CONSTITUTION.md`.

## التشغيل على الجهاز

أمر واحد يشغّل الموقع:

```
npm run dev
```

بعدها افتح الرابط اللي يطلع في الشاشة. على الجوال (نفس الواي فاي) افتح الرابط اللي يبدأ برقم الجهاز، مثل:

```
http://192.168.x.x:4321/
```

صفحة المراجعة (الدرجات والإضافات) على:

```
/review/
```

## شلون تضيف فيديو يدويًا

1. حط ملف الفيديو في مجلد الفيديوهات باسم `tk_<رقم الفيديو>.mp4`، ورقم الفيديو هو الرقم اللي في رابط تيك توك.
2. أضف سطر للفيديو في الملف `data/topics.json`: مفتاح بالإنجليزي، ورقم الفيديو الأساسي، وأرقام الفيديوهات الثانية اللي عن نفس الموضوع.
3. شغّل هالأوامر بالترتيب:

```
node scripts/analyze.js --topics
```

```
node scripts/write.js
```

```
node scripts/build-page.js
```

كل خطوة تحفظ نتيجتها جنب ملف الفيديو، فما ندفع على نفس الفيديو مرتين.

## اللغات

الموقع جاهز للخمس لغات (العربية، الإنجليزية، الفرنسية، الإسبانية، الأردو)، بس المنشور الحين العربي بس. اللغة ما تظهر في المبدّل إلا إذا صار لها محتوى.
لإضافة الترجمات الأربع لكل الصفحات:

```
node scripts/write.js --langs ar,en,fr,es,ur
```

```
node scripts/build-page.js
```

## المفاتيح

مفتاح OpenRouter يكون في ملف `.env` بس، وهالملف ما ينرفع على GitHub. التكلفة كلها تنحفظ في `data/spend.json`.

## الملفات المهمة

- `content/videos/<اللغة>/` : ملف لكل صفحة.
- `data/topics.json` : الفيديوهات وتجميعها حسب الموضوع.
- `data/scores.json` : درجات الجودة (ست أبعاد، كل بُعد من 10).
- `content/_archive/` : أي صفحة تنشال تروح هنا، ما تنحذف نهائيًا.
